### Довідник спільних модулів

Скористайтеся ним, перш ніж писати нову математику: найімовірніше, потрібна функція вже є. Повні коментарі лежать у самих файлах.

- **`Stat`** (`common.js`): `fmt(v, digits)`, `fmtSigned`, `fmtSig` (4 значущі цифри), `decimalsFor`, `snapToSpan`, `clamp`; осі: `niceStep`, `ticksFor(lo, hi, target)` → `{step, decimals, major, minor}`; `mean`, `pearson`, `spearman`, `ranks`, `pValue`, `fisherCI`, `analyze(points)`; спеціальні функції `lgamma`, `betai`; розбір вводу `toNumber`, `splitLine`, `parseData`.
- **`Dist`** (`distributions.js`): розподіли `binomial`, `geometric`, `poisson`, `hypergeometric` (дискретні: `pmf`, `cdf`, `support`) і `normal`, `exponential`, `uniform`, `chisq`, `student`, `fisher` (неперервні: `pdf`, `cdf`, `domain`); у всіх `mean(P)`, `variance(P)` (`null` означає «не існує», `Infinity` «розбіжне»); `gammaP`, `gammaQ`, `quantile`, `quantileDiscrete`; довірчий інтервал для математичного сподівання `critical(kind, level, df)` і `meanCI(values, level, method, opts)` (методи `"z"`, `"t"`, `"zs"`).
- **`Prob`** (`probability.js`): `setWeight`, `resize` (ваги гіпотез із сумою 1), `total`, `terms`, `posterior`, `sequence`, `apportion`, `counts`; для двох подій `jointRange`, `clampJoint`, `table2x2`, `cond`, `independence`; для трьох `independence3`.
- **`Summ`** (`summary.js`): за окремими значеннями `sorted`, `mean`, `median`, `quartiles`, `variance(v, ddof)`, `sd`, `series`, `modeRaw`, `box`; для інтервального ряду `group(v, start, h)` (за вимірами), `table(start, h, freqs)` (за готовими частотами), `gMean`, `gVariance`, `gQuantile(g, p)`, `gMode`. Структура ряду: `{start, h, n, m, iv: [{a, b, mid, f, cum}]}`.
- **`Approx`** (`approximations.js`, потребує `Dist`): `exactPmf`, `exactProb(n, p, a, b)`, `localNormal` (локальна теорема Муавра–Лапласа), `normalProb(n, p, a, b, поправка)` (інтегральна теорема), `poissonPmf`, `poissonProb(λ, a, b)`, відстані за варіацією `tvNormal`, `tvPoisson`, `window` (діапазон k для графіка), `rules` (орієнтири npq ≥ 10 і p ≤ 0,1).
- **`Geom`** (`geometry.js`): `circleProb(r)`, `circleHit`, `quarterProb`, `quarterHit`, `piFromQuarter(k, n)`, `meetingProb(T, τ)`, `meetingHit`, `buffonProb(l, d)` (лише l ≤ d), `buffonHit(l, x, θ)`, `piFromBuffon`, `bertrandMethods`, `bertrandProb(спосіб)`, `bertrandChord(спосіб, u, v)`, `se(p, n)`. Випадкові координати передає сторінка (з `Rand`).
- **`Comb`** (`combinatorics.js`): `fact(n)`, `perm(n,k)`, `permRep`, `comb`, `combRep`, `count(kind,n,k)` (`"A"`, `"Arep"`, `"C"`, `"Crep"`) повертають BigInt; `multinomial(counts)`, `group(b)`, `sci(b)`, `ratio(a,b)`, `birthdayDistinct(n,k)`, `lotteryExact(N,K,m)`, `list(kind,n,k,limit)`, `listMulti(counts,limit)`.
- **`Walk`** (`walk.js`, потребує `Dist`): `positionPmf(n, j, p)`, `u(m)`, `uArray(m)`, `arcsinePmf(m)` (P(L = 2k) = u₂ₖ·u₂ₘ₋₂ₖ), `noReturn(m)`, `ruinProb(a, b, p)`, `duration(a, b, p)`; симуляції з генератором `rng`: `path(rng, n, p)`, `leadSteps(шлях)`, `game(rng, a, b, p, maxSteps, keep)`.
- **`Data`** (`datasets.js`): `Data[id][стовпець]` це масив значень. Сторінки беруть n, x̄, s з даних через `Summ`, а не вписують числа вручну. **`DataView.render(host, {cols, file, dec})`** будує блок «Дані»; `DataView.csv(cols)` повертає текст CSV.
- **`Norm`** (`normality.js`, потребує `Dist`): `qq(значення)` → `{z, x, slope, intercept}` (позиції Бломма, пряма через квартилі), `qqTheoretical(n)`, `shapiroWilk(значення)` → `{W, p, n}` або `null` (n від 3 до 5000, наближення Ройстона), `chiSquare(значення, K, mode, params?)` → `{chi2, df, p, edges, observed, expected, small}` (`mode` це `"prob"` або `"width"`; df = K − 3, якщо μ і σ оцінено, і K − 1, якщо задано в `params`).
- **`Hyp`** (`hypotheses.js`, потребує `Dist`): два незалежні середні: `twoMeans(n1, n2, x̄1, x̄2, s1, s2, method)` → `{diff, se, stat, df}` (`method` це `"z"`, `"welch"` або `"pooled"`; для z на вході σ, df = ∞), `pValueDf(стат, df, tail)`, `criticalDf(α, df, tail)`, `diffBound(diff, se, df, α, tail)`; z- і t-критерій для одного середнього у єдиному записі `kind` = `"z"` (σ відома) або `"t"` (σ невідома, n − 1 ступенів): `pValueNull(стат, kind, n, tail)`, `criticalNull(α, kind, n, tail)`, `meanBound(x̄, σ або s, n, α, kind, tail)` (довірчий інтервал або межа, двоїсті до критерію); `zStat(x̄, μ₀, σ, n)`, `critical(α, tail)` (межі для z), `criticalMean(μ₀, σ, n, α, tail)` (межі для x̄), `reject(z, α, tail)`, `pValue(z, tail)`, `power(μ, μ₀, σ, n, α, tail)`, `sampleSize(μ, μ₀, σ, α, tail, ціль)` (найменше n для потужності, `null` якщо μ не в H₁), `inAlternative(μ, μ₀, tail)`; частки: `propZ(x, n, p₀, tail)` → `{phat, se, z, p}`, `propRuleOk(n, p₀)` (орієнтир np₀(1 − p₀) ≥ 10), `propExactP(x, n, p₀, alt)` (точний біноміальний p, двосторонній як у scipy), `twoPropZ(x₁, n₁, x₂, n₂, tail)` → `{p1, p2, diff, pooled, se, z, p}` (загальна частка в se; `z` і `p` дорівнюють `null`, якщо se = 0), `twoPropCI(x₁, n₁, x₂, n₂, рівень)` (Вальд, окремі p̂ᵢ), `twoPropRuleOk` (≥ 10 успіхів і невдач у кожній групі); біноміальний критерій H₀: θ = ½: `binomPmf(n, k)`, `binomPValue(n, k, alt)`, `binomExtreme(n, k, j, alt)` (чи стовпчик j у хвості «не менш крайніх»), `binomCritical(n, α, alt)` → `{k, size}` або `null`; `alt` це `"right"`, `"left"`, `"two"`; `tail` це `"two"`, `"right"` або `"left"`. Для односторонньої альтернативи H₀ розуміємо як μ ≤ μ₀ (μ ≥ μ₀).
- **`Reg`** (`regression.js`, потребує `Dist`): `fit(точки {x, y})` → `{n, df, xbar, ybar, sxx, b, a, fitted, res, sse, sst, r2, s, seB, seA, h, stdres, cook}` або `null` (n < 2 чи однакові x; `s`, `stdres`, `cook` дорівнюють `null` при n = 2 або s = 0; `r2` — `null`, якщо всі y однакові); `predict(m, x)`; `slopeCI(m, рівень)` (t з n − 2 ступенями; `null` при n ≤ 2); `without(точки, i)` — модель без i-ї точки. Орієнтири впливу: hᵢ > 4/n, Dᵢ > 1.
- **`Tex`** (`formulas.js`): `set(el, запис, [latex])` записує формулу в елемент; `text(el, рядок)` вставляє текст і сам знаходить у ньому формули; `mix(el, [рядок, {m: запис}, …])` змішаний підпис (у рядку для `text` одиночні літери-формули позначаємо як `$z$`); `render(корінь)` домальовує `.tex`; `toTex(запис)` перетворює простий запис на LaTeX (без DOM, тестується).
- **`Rand`** (`random.js`): `create(seed)` повертає генератор з методами `next`, `int`, `uniform`, `bernoulli`, `normal`, `exp`, `cauchy`, `arcsine`, `bimodal`; `seedFor(seed, i)` дає окреме зерно для i-го запуску.

### Відомі пастки

- **Нова функція у спільному файлі й кеш.** Якщо сторінка використовує функцію, яку щойно додали в `random.js`, `summary.js` чи інший спільний файл, а автор завантажив лише сторінку, на сайті спрацює стара версія файлу й кнопки «мовчки» перестануть працювати. Тому при кожній зміні спільного файлу перелічуйте його у списку для завантаження й нагадуйте про Ctrl+F5.
- **Полотно ще не має розмірів.** Якщо сторінку рахують до першого `ResizeObserver`, ширина `canvas` дорівнює нулю: захищайтеся від від'ємних радіусів і ділення на нуль під час малювання.
- **Крайні значення інтервалу.** Максимум на верхній межі останнього інтервалу не створює додаткового інтервалу: див. `Summ.group`. Не повертайтеся до `floor((max − x₀)/h) + 1`.
- **Знімки екрана в Playwright.** Після зміни стану зачекайте приблизно 1 секунду перед `fullPage`, інакше знімок може зависнути через таймер `aria-live`.
