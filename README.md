# Інтерактивні сторінки

Навчальні сторінки, на яких можна самостійно змінювати дані й одразу бачити результат.
Це звичайні HTML-файли, без збірки й без встановлення чогось на комп'ютер.

## Що де лежить

| Файл | Призначення |
|---|---|
| `index.html` | Головна: перелік сторінок за дисциплінами |
| `discrete-summaries.html` | «Числові характеристики: дискретна ознака»: частоти значень, стовпчики, ящик з вусами, кумулята |
| `continuous-summaries.html` | «Числові характеристики: неперервна ознака»: інтервальний ряд, гістограма, полігон, кумулятивна крива |
| `correlation.html` | Сторінка «Коефіцієнт кореляції» (одна тема = один файл) |
| `distributions.html` | Сторінка «Розподіли ймовірностей»: 10 розподілів, калькулятор ймовірностей |
| `large-numbers.html` | Сторінка «Закон великих чисел»: серії дослідів, графік середніх і відхилення суми |
| `central-limit.html` | Сторінка «Центральна гранична теорема»: розподіл середніх n чисел, нормальна крива, середнє / медіана / максимум |
| `total-probability.html` | Сторінка «Формула повної ймовірності»: 2–4 гіпотези, квадрат і дерево ймовірностей |
| `bayes.html` | Сторінка «Формула Байєса»: тисяча випадків, кілька результатів підряд, симуляція, готові задачі |
| `common.css` | Спільний вигляд: кольори, шрифти, кнопки, світла й темна тема |
| `common.js` | Спільні розрахунки: кореляція, p-значення, довірчий інтервал, розбір даних, осі |
| `distributions.js` | Математика розподілів: ймовірності, щільності, функції розподілу, середнє, дисперсія |
| `probability.js` | Математика повної ймовірності й формули Байєса |
| `summary.js` | Математика числових характеристик: для окремих значень і для інтервального ряду |
| `random.js` | Випадкові числа із зерном (результат симуляції можна відтворити) |
| `tests/` | Перевірка розрахунків (для сайту не потрібна) |
