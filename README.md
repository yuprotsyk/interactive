# Інтерактивні сторінки

Навчальні сторінки, на яких можна самостійно змінювати дані й одразу бачити результат.
Це звичайні HTML-файли, без збірки й без встановлення чогось на комп'ютер.

## Що де лежить

| Файл | Призначення |
|---|---|
| `index.html` | Головна: перелік сторінок за дисциплінами |
| `correlation.html` | Сторінка «Коефіцієнт кореляції» (одна тема = один файл) |
| `common.css` | Спільний вигляд: кольори, шрифти, кнопки, світла й темна тема |
| `common.js` | Спільні розрахунки: кореляція, p-значення, довірчий інтервал, розбір даних, осі |
| `tests/` | Перевірка розрахунків (для сайту не потрібна) |

## Як виставити на GitHub Pages

1. Зареєструйтеся на github.com (безкоштовно) і створіть репозиторій: **New repository**, назва, наприклад, `statystyka`, тип **Public**.
2. Натисніть **uploading an existing file**, перетягніть файли `index.html`, `correlation.html`, `common.css`, `common.js` (і за бажанням папку `tests`) та натисніть **Commit changes**.
3. Відкрийте **Settings → Pages**. У розділі **Build and deployment** оберіть **Deploy from a branch**, гілку **main**, папку **/ (root)** і натисніть **Save**.
4. Через 1–2 хвилини сайт з'явиться за адресою `https://ваш-логін.github.io/statystyka/`. Адресу покаже сам GitHub угорі тієї ж сторінки.

Щоб оновити сайт, відкрийте файл у репозиторії, натисніть олівець (редагувати), змініть і натисніть **Commit changes**. Зміни з'являються за хвилину.

## Як додати нову тему

1. Скопіюйте `correlation.html` у новий файл, наприклад `regression.html`, і змініть зміст.
   Кольори, кнопки й розрахунки беруться зі спільних `common.css` та `common.js`, тому їх переписувати не треба.
2. У `index.html` скопіюйте один блок `<li class="topic">` і змініть посилання, назву й опис.
   Для нової дисципліни скопіюйте цілий блок `<section class="subject">` і змініть його заголовок.
3. Завантажте файли на GitHub, як описано вище.

## Як змінити готові набори даних

У `correlation.html` знайдіть `var PRESETS`. Кожен набір це запис із назвою, поясненням і точками
(або викликом `corrSet(кількість, r, ...)`, який створює точки із заданим r). Скопіюйте один запис, змініть і збережіть.

## Керування з клавіатури (сторінка кореляції)

Клавіша `Tab` переводить на поле. Стрілки рухають курсор (з `Shift` швидше), `Enter` додає точку,
`[` і `]` вибирають точку, стрілки тоді рухають її, `Delete` видаляє, `Esc` скасовує вибір, `Ctrl+Z` скасовує дію.
Усі точки також є в таблиці під полем, їх можна змінювати й видаляти без миші.

## Перевірка розрахунків (за бажанням)

Потрібен лише Node 18 або новіший. У папці проєкту:

```
node --test tests/check.mjs
```

Тести порівнюють r, ρ Спірмена, p-значення, довірчий інтервал і пряму регресії з еталоном зі scipy на 112 наборах.
Файл `tools/gen_fixtures.py` створює ці еталонні значення (потрібні Python із scipy).

## Шрифти

і все працює.
