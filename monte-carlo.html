Метод Монте-Карло

Метод Монте-Карло оцінює інтеграл за випадковими точками. Оберіть функцію й метод, додайте точки та стежте, як оцінка наближається до точного значення, а стандартна похибка (за скінченної дисперсії) спадає пропорційно 1/√n.

Інтеграл

Метод
Рівень довіри

Випадкові точки

Оцінка інтеграла

Похибка залежно від n

Результат

Що тут відбувається

Метод Монте-Карло. Інтеграл є математичним сподіванням: ∫ₐᵇ f(x)dx = (b − a)·E f(U)⁠, де U⁠ рівномірно розподілена на [a; b]⁠. Тому середнє значення (b − a)f⁠ у випадкових точках оцінює інтеграл. Похибка спадає як 1/√n⁠.

Докладніше: формули й пояснення

Метод середнього значення. Візьміть незалежні U₁, …, Uₙ⁠ рівномірні на [a; b]⁠. Оцінка Î = (b − a)/n · Σ f(Uᵢ)⁠ незміщена: E Î = I⁠. Її стандартну похибку оцінюють як s/√n⁠, де s⁠ — вибіркове стандартне відхилення доданків vᵢ = (b − a)f(Uᵢ)⁠.

Метод влучання. Нехай 0 ≤ f ≤ M⁠. Кидайте точки рівномірно в прямокутник [a; b] × [0; M]⁠. Імовірність влучити під криву дорівнює p = I/((b − a)M)⁠. Тому Î = (b − a)M·p̂⁠, де p̂⁠ — частка влучань.

Яка оцінка точніша. Дисперсія одного доданка: для середнього значення σ² = (b − a)∫f² dx − I²⁠, для влучання σ² = I((b − a)M − I)⁠. Для 0 ≤ f ≤ M⁠ маємо ∫f² ≤ M∫f⁠, тому дисперсія методу середнього значення не більша, ніж методу влучання. Дисперсія оцінки за n⁠ точок дорівнює σ²/n⁠.

Швидкість збіжності. Стандартна похибка дорівнює σ/√n⁠. Щоб зменшити її вдесятеро, треба у 100 разів більше точок. На графіку в логарифмічному масштабі це пряма з нахилом −½.

Довірчий інтервал. Î ± z₁₋α/₂·s/√n⁠ — наближений: він спирається на центральну граничну теорему й вимагає скінченної дисперсії доданка. Для малого n⁠ фактичне покриття може відрізнятися від заданого рівня.

Нескінченна дисперсія. Для f(x) = 1/√x⁠ на (0; 1]⁠ інтеграл I = 2⁠ скінченний, а ∫f² dx = ∫dx/x⁠ розбігається. Дисперсія доданка нескінченна. Оцінка Î⁠ збігається до I⁠ за законом великих чисел, але формули σ/√n⁠ та інтервал не застосовні.

Оцінка числа π. Для √(1 − x²)⁠ і 1/(1 + x²)⁠ на [0; 1]⁠ інтеграл дорівнює π/4⁠, тому π ≈ 4Î⁠.
