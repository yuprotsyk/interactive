# Інтерактивні сторінки

Колекція навчальних вебсторінок з теорії ймовірностей і математичної статистики. На кожній сторінці можна самостійно змінювати дані чи параметри й одразу бачити, як змінюються графіки та результати.

**Живий сайт:** <https://yuprotsyk.github.io/interactive/>

Усе це звичайні HTML-файли: без збірки, без серверної частини, без встановлення чогось на комп'ютер. Працює на GitHub Pages і відкривається просто з диска.

## Сторінки

### Теорія ймовірностей

| Сторінка | Що можна робити |
|---|---|
| [Розподіли ймовірностей](distributions.html) | Обрати один із 10 розподілів, змінювати параметри, дивитися щільність чи функцію розподілу, обчислювати ймовірність потрапляння в проміжок |
| [Закон великих чисел](large-numbers.html) | Запускати серії дослідів (монета, кубик, випадкові числа, Коші) і дивитися, як середнє наближається до математичного сподівання |
| [Центральна гранична теорема](central-limit.html) | Дивитися, як розподіл середніх n чисел наближається до нормального, і порівнювати середнє, медіану та максимум |
| [Умовна ймовірність і незалежність подій](conditional.html) | Задавати ймовірності двох подій на мозаїці, «звужувати» простір до однієї з них, перевіряти незалежність, розбирати типові помилки, зокрема попарну незалежність трьох подій |
| [Формула повної ймовірності](total-probability.html) | Задавати 2–4 гіпотези й бачити, як із них складається P(A): квадрат ймовірностей і дерево |
| [Формула Байєса](bayes.html) | Переоцінювати гіпотези після події: тисяча випадків, кілька результатів підряд, симуляція, готові задачі |

### Статистика

| Сторінка | Що можна робити |
|---|---|
| [Числові характеристики: дискретна ознака](discrete-summaries.html) | Задавати частоти значень і дивитися середнє, медіану, моду, квартилі, дисперсію; стовпчики, ящик з вусами, кумулята |
| [Числові характеристики: неперервна ознака](continuous-summaries.html) | Працювати з інтервальним рядом: гістограма, полігон, кумулятивна крива, мода й медіана за формулами інтервального ряду |
| [Довірчі інтервали для математичного сподівання](confidence-intervals.html) | Дивитися на серію інтервалів за багатьма вибірками, порівнювати z, t і хибний «z із s», будувати інтервал за власними даними |
| [Коефіцієнт кореляції](correlation.html) | Ставити й рухати точки на діаграмі розсіювання, бачити r, ρ Спірмена, p-значення й довірчий інтервал |

## Як переглянути локально

Збірки немає, тож достатньо відкрити `index.html` у браузері подвійним клацанням.

Якщо браузер обмежує роботу з локальними файлами, запустіть простий сервер із кореня проєкту й відкрийте адресу, яку він покаже:

```bash
python3 -m http.server 8000
# потім відкрити http://localhost:8000
```

Шрифти підвантажуються з Google Fonts. Без інтернету сторінки працюють зі стандартними шрифтами системи.
Формули відображає KaTeX, який підвантажується з CDN (jsDelivr). Без інтернету формули лишаються простим текстом, решта сторінки працює.

## Як перевірити розрахунки

Для математичних тестів потрібен Node.js 18 або новіший. Сторінки на ньому не залежать.

```bash
node --test tests/*.mjs
```

Тести порівнюють наші формули з еталонними значеннями, обчисленими в Python (scipy, numpy).

Браузерні тести відкривають кожну сторінку в Chromium і перевіряють числа, крайні випадки, телефонну ширину та темну тему:

```bash
npm install
npx playwright install chromium
npm run test:browser
```

На GitHub обидва набори запускаються автоматично при кожному завантаженні файлів (вкладка Actions). Подробиці описано в [CLAUDE.md](CLAUDE.md).

## Структура

| Файл | Призначення |
|---|---|
| `index.html` | Головна: перелік сторінок за розділами |
| `*.html` | Сторінки, одна тема = один файл |
| `common.css` | Спільний вигляд: кольори, шрифти, кнопки, світла й темна тема |
| `common.js` | Спільні розрахунки: форматування чисел, осі, кореляція, p-значення, розбір даних (`Stat`) |
| `distributions.js` | Математика розподілів (`Dist`) |
| `probability.js` | Повна ймовірність і формула Байєса (`Prob`) |
| `summary.js` | Числові характеристики: окремі значення й інтервальний ряд (`Summ`) |
| `random.js` | Випадкові числа із зерном: результат симуляції можна відтворити (`Rand`) |
| `formulas.js` | Відображення формул через KaTeX із запасним простим записом (`Tex`) |
| `tests/` | Перевірка розрахунків (`*.mjs`) і браузерні тести (`browser/`), для сайту не потрібні |
| `package.json` | Лише для тестів (Playwright) |
| `.github/workflows/` | Автоматичний запуск тестів на GitHub |
| `tools/` | Скрипти Python, що створюють еталонні дані для тестів |
