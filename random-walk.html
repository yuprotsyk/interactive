На кожному кроці траєкторія йде на 1 вгору або на 1 вниз. Напрям визначає монетка. Сторінка показує три результати: розкид положень, розорення гравця й час вище нуля.

Показники

Що тут відбувається

Модель. S₀ = 0⁠. Sₙ = X₁ + … + Xₙ⁠. Кроки Xᵢ незалежні. P(Xᵢ = 1) = p⁠, P(Xᵢ = −1) = q = 1 − p⁠. Для чесної монети p = ½⁠.

Докладніше: формули й пояснення

Положення. Нехай K це кількість кроків вгору. Тоді Sₙ = 2K − n⁠, де K ~ Bin(n, p)⁠. E(Sₙ) = n(p − q)⁠. D(Sₙ) = 4npq⁠. Для p = ½ стандартне відхилення дорівнює √n⁠: 10 при n = 100⁠, 100 при n = 10 000⁠.

Повернення в нуль. Для p = ½ ймовірність бути в нулі в момент 2m дорівнює u₂ₘ = C₂ₘᵐ/4ᵐ⁠. У непарні моменти вона дорівнює 0. За формулою Стірлінга u₂ₘ ≈ 1/√(πm)⁠. Те саме число u₂ₘ є ймовірністю події S₁ ≠ 0, …, S₂ₘ ≠ 0⁠. Ця ймовірність прямує до 0 при m → ∞⁠. Тому з імовірністю 1 траєкторія повертається в нуль.

Розорення гравця. Гравець має a грн, суперник має b грн, N = a + b⁠. Кожен раунд змінює капітал гравця на +1 або −1. Гра триває, поки капітал гравця не стане 0 або N⁠. Для p = ½⁠: ймовірність розорення b/N⁠, очікувана тривалість ab⁠. Для p ≠ ½ нехай r = q/p⁠: ймовірність розорення (rᵃ − rᴺ)/(1 − rᴺ)⁠, очікувана тривалість (a − N(1 − rᵃ)/(1 − rᴺ))/(q − p)⁠. Для p = ½ ймовірність розорення тим більша, чим менше a і чим більше b⁠.

Закон арксинуса. Траєкторія вище нуля в момент i⁠, якщо Sᵢ > 0⁠, або Sᵢ = 0 і Sᵢ₋₁ > 0⁠. Нехай L це кількість таких моментів серед перших 2m⁠. Для p = ½⁠: P(L = 2k) = u₂ₖ·u₂ₘ₋₂ₖ⁠. Ймовірність найбільша при L = 0 і L = 2m⁠, найменша посередині. Для великого m⁠: P(L/2m < x) ≈ (2/π)·arcsin √x⁠. Щільність цього розподілу: 1/(π√(x(1 − x)))⁠, x ∈ (0; 1)⁠. Проміжок 0,4…0,6 і два краї (до 0,1 та від 0,9) мають однакову сумарну довжину 0,2, але краї ймовірніші: див. показники.
